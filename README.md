# Replication Code for "Hours Inequality"
This repository contains the replication material, code, and documentation required to reproduce all empirical analyses, tables, and figures in the manuscript **"Hours Inequality"**, submitted to the *European Sociological Review*.

## 📂 Repository Structure & Files
The repository includes the following components:
1. **`Data_description.docx` (Word File):** 
   * Provides a comprehensive overview of the individual-level data.
   * Explains the entire data cleaning, harmonization, and variable construction workflow.
   * Embedded within this document is the full **R code** used to process the individual national surveys and generate the standardized, cross-national common variables.
2. **`shocks_oecd.xlsx` (Excel File):** 
   * Contains the macroeconomic indicator data collected from publicly available OECD databases. This file is clean, complete, and fully provided in the repository.
3. **`hoursinequality.do` (Stata Script):** 
   * The primary analytical script. It imports the (locally generated) individual data file alongside `shocks_oecd.xlsx` to compute all descriptive statistics, run the regression models, and generate every table and figure presented in the paper.

## 📊 Data Access & Availability Statement

Due to strict data protection regulations, institutional licensing agreements, and third-party terms of use, the final integrated file **`individual data`** (the file generated by the R cleaning pipelines) **cannot be distributed** within this repository. 

To replicate the study from scratch, researchers must independently secure access to the microdata directly from the official national data providers:
* **United States (CPS):** Available via [IPUMS CPS](https://ipums.org).
* **United Kingdom (BHPS & Understanding Society):** Available via the [UK Data Service](https://ukdataservice.ac.uk).
* **Germany (SOEP):** Available via the [DIW Berlin / SOEP Research Data Center](https://diw.de).
* **France (Enquête Emploi):** Available via [PROGEDO-ADISP / Réseau Quetelet](https://progedo-adisp.fr).

The macroeconomic companion data, `shocks_oecd.xlsx`, is compiled entirely from public [OECD Data](https://oecd.org) and is included directly in this repository for immediate use.


## 🛠️ Software & System Requirements

* **Data Cleaning & Harmonization:** R — *See code embedded in `Data_description.docx`*.
* **Analysis & Visualization:** Stata — *Uses the provided Stata `.do` file*.

## 🚀 Instructions for Replication

To execute the replication package and verify results:

### Phase 1: Data Preparation & Harmonization
1. Secure administrative access and download the raw national files from the four data providers listed above.
2. Extract the **R code** from `Data_description.docx`.
3. Update the global filepaths in the R scripts to point to your local directories housing the raw data files.
4. Run the R script. This pipeline cleans and merges the national datasets.

### Phase 2: Statistical Analysis
1. Place your newly created `individual data` file, the provided `shocks_oecd.xlsx` file, and the provided Stata script into your active Stata working directory.
2. Open the Stata script and modify the directory filepath command at the top of the file to match your folder environment.
3. Execute the Stata script to process the combined dataset and generate all final tables and figures.
